# Workflow : Nouveau projet

## Étapes
1. Créer le dossier du projet
2. `git init`
3. Créer la structure de base (src/, tests/, docs/)
4. Initialiser `package.json` ou `pyproject.toml` selon le langage
5. Créer un `.gitignore` adapté
6. Créer un README.md minimal
7. Premier commit

## Commande rapide
```bash
python scripts/scaffold_project.py <nom> --lang python|node
```
